# Document writing

These rules apply to any document. They cover the structure of the text, the choice of words, and punctuation. They do not depend on the topic or on the type of assignment.

If the guideline of a document requires something else, follow the guideline at that point.

## Language

Write the document in the language that the user asks for. If the user does not ask for a language, use the language of the request. Apply every rule in that language, with the connectors from the table in rule 1.

## Structure

1. Give each paragraph one thread. Make each sentence rest on the previous sentence. Express the relation between sentences with connectors of cause and consequence. Do not let a paragraph read as a list of loose ideas.

   | English | Spanish |
   |---------|---------|
   | so, therefore, for this reason | por lo que, por eso |
   | since, because | ya que, puesto que |
   | for that purpose | para eso |
   | in addition to | además de |

2. If two consecutive sentences are related, join them with a connector. A run of short sentences separated by periods reads as an enumeration.
3. Give each decision with the reason for it. The text must explain why something was done, not only what was done.
4. Do not add filler. Delete a sentence, note, or clarification that does not help the reader. Do not state the obvious.
5. Match the strength of each claim to its support. Use absolute words such as "always", "never", or "fails to" only when the text proves them. Otherwise, use a limited phrase such as "has difficulty with".

## Words

6. Use literal words of common use. Avoid figurative, colloquial, or journalistic expressions. If you are not sure, choose the simpler word.
7. Write in the positive. Say what is done. Avoid contrasts of the type "X instead of Y".
8. Make references specific. "The structure of the presentation" is clearer than "the structure".
9. Name one concept with one term, always. Choose the term that the reader understands.
10. Define an acronym that the reader does not know at its first use. Use the acronym from that point. Do not define a common acronym.
11. Put terms from another language in italics.
12. Use a formal but natural register. Use the grammatical person that the document requires, and keep it in the whole text. In a personal text, write in the first person singular ("I attended", "I understood that"). If the document requires an impersonal style, follow that requirement.

## Punctuation

13. Use a colon only to introduce an enumeration or after a label, such as "Source:". A colon never introduces an explanation or announces an idea. In those cases, use a connector or a new sentence.
14. Do not use a semicolon. Separate the ideas with a period or join them with a connector.
15. Do not use dashes to insert a remark. Put the remark between commas.
16. Use parentheses only for short clarifications. Do not use them to introduce acronyms.

## Content

Use these rules for a text that the user will sign, such as a report or a university assignment.

17. Write only what the user told you or what the sources that the user gave can prove. Do not state facts, circumstances, or plans of the user that the user did not give. Do not treat something as defined if it is not defined yet. If you need a datum about the user, ask for it or leave it out.
18. The opinions belong to the user. Do not invent criticism to balance the text. Do not soften what the user liked. If the user has one objection, write only that objection.
19. Do not compare with other people or other works unless the user asks.
20. Use only public data that readers can verify, and only the data that matches what the user did or lived. Do not add metrics that you calculated or analysis that the user did not ask for. Give each datum with its source.
21. If the guideline of the document asks for acronyms in footnotes, define each acronym in a footnote at its first use.

## Format and closing

22. Write a formal declaration, such as the statement of AI use, on one line. The statement of AI use names the tool and says what the user used it for.
23. Before you call a text finished, read the rules of the course or of the document and make sure that the text follows them. Check the length, the file name, and the name and source of each table and figure. If the table is the work of the user and the data comes from other authors, write the source in this form, and put the full reference in the document:

    | English | Spanish |
    |---------|---------|
    | Own elaboration, information taken from [Author, year] | Elaboración propia, información extraída de [Autor, año] |

24. Keep the length that the user asked for. If a change from the user makes the text longer than the limit, say what you would cut to make up for it.

## Working with the user

25. Apply the changes as the user asks. If you disagree with a change, say so with concrete arguments and propose an alternative. The decision belongs to the user.
26. When you rewrite a text, show the final text. Then list what else you changed so that the text fits or stays coherent.

## Examples

These pairs show the criterion. Do not copy them into texts.

### English

| No | Yes |
|----|-----|
| The model has one limitation: it is too slow for real-time operation. | The model has one limitation, since it is too slow for real-time operation. |
| The data is imbalanced; therefore the macro F1 metric is used. | The data is imbalanced, so the macro F1 metric is used. |
| Three datasets were used. They are public. They allow comparison with previous work. | Three public datasets were used, since they allow comparison of the results with those of previous work. |
| The system—which runs locally—sends no data to third parties. | The system, which runs locally, sends no data to third parties. |
| Current systems cannot process large volumes of data. | Current systems have difficulty processing large volumes of data. |
| The method is the cornerstone of the project. | The method is the basis of the project. |
| A small model was chosen instead of a large one. | A small model was chosen, since it costs less to run. |
| The structure was modified. | The structure of the report was modified. |

Correct use of a colon, because it introduces an enumeration: "The system has three components: a flow extractor, a classifier, and an alert module."

### Spanish

| No | Sí |
|----|----|
| El modelo tiene una limitación: es demasiado lento para operar en tiempo real. | El modelo tiene una limitación, ya que es demasiado lento para operar en tiempo real. |
| Los datos están desbalanceados; por eso se usa la métrica F1 macro. | Los datos están desbalanceados, por lo que se usa la métrica F1 macro. |
| Se usaron tres conjuntos de datos. Son públicos. Permiten comparar con trabajos previos. | Se usaron tres conjuntos de datos públicos, puesto que permiten comparar los resultados con los de trabajos previos. |
| El sistema —que se ejecuta localmente— no envía datos a terceros. | El sistema, que se ejecuta localmente, no envía datos a terceros. |
| Los sistemas actuales no logran procesar grandes volúmenes de datos. | Los sistemas actuales tienen dificultades para procesar grandes volúmenes de datos. |
| El método es la piedra angular del proyecto. | El método es la base del proyecto. |
| Se eligió un modelo pequeño en vez de uno grande. | Se eligió un modelo pequeño, ya que cuesta menos ejecutarlo. |
| Se modificó la estructura. | Se modificó la estructura del informe. |

Uso correcto de los dos puntos, porque introducen una enumeración: «El sistema tiene tres componentes: un extractor de flujos, un clasificador y un módulo de alertas.»
